# PebbleDB

PebbleDB is an embedded Log-Structured Merge (LSM) tree based key-value storage engine implemented in C++.

## Planned Features

- Write-Ahead Logging (WAL)
- MemTables
- Immutable MemTables
- SSTables
- Bloom Filters
- Sparse Index
- Background Flush
- Size-based Compaction
- Crash Recovery
